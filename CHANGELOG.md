# Changelog

## 0.1.0 — 2026-11-22

- First release, published as **CodeTrail** (Marketplace display name **CodeTrail Live**,
  extension ID `smh-dev-ai.codetrail`).
- Live timeline for edits, saves, file create/delete/rename, external changes, tasks,
  debug sessions, and terminal commands.
- Line and word-level diffs with hunks, old/new line numbers, and explicit truncation
  states.
- Sidebar and editor panel surfaces, About page, status bar, commands, and keybinding.
- English and Persian UI with RTL support; full VS Code theme integration including
  light, dark, and high-contrast themes.
- Local-only persistence, JSON/Markdown export, filters, search, and pause/clear controls.
- Works automatically in every workspace with editor-integrated agents and with CLI agents
  that write to disk; no per-project setup.
